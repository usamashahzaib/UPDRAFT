## Code gaps closed in this audit

- Online touch controls now label an armed-pad action **LAUNCH**.
- Online shots now use the camera-selected point and a server-side muzzle origin, with local recoil and blocked-shot feedback.
- Slowdown-only aim assist now uses the same 3-degree, 25-metre, 70-percent settings in offline and online play, with line-of-sight checks.
- Online contextual pings now use server-classified visible targets, team broadcast, and a server-enforced two-second cooldown.

These are source changes only; they still need the documented Android and multiplayer acceptance runs.
