## Code gaps closed in this audit

- Online touch controls now label an armed-pad action **LAUNCH**.
- Online shots now use the camera-selected point and a server-side muzzle origin, with local recoil and blocked-shot feedback.
- Slowdown-only aim assist now uses the same 3-degree, 25-metre, 70-percent settings in offline and online play, with line-of-sight checks.
- Online contextual pings now use server-classified visible targets, team broadcast, and a server-enforced two-second cooldown.

These are source changes only; they still need the documented Android and multiplayer acceptance runs.

## Gate C implementation follow-up (2026-09-28)

- Set Fusion tick selection to 30 client ticks/s with a server tick divisor of 1 and retained the 150 ms hitbox rewind buffer in `ProjectUpdraft/Assets/Photon/Fusion/Resources/NetworkProjectConfig.fusion`.
- Hardened server admission against replayed tickets, two simultaneous connections for one account, ticket/match mismatch, and team mismatch. Admission remains backend-authenticated in production; insecure development tickets do not count as acceptance.
- Added a client reconnect loop that checks the authenticated reconnect endpoint, requests a fresh join ticket, shows retry state with a cancel action, and rejoins the preserved avatar. It has not been compiled or exercised in Unity.
- Expired allocator leases now cancel their still-matched reservations without creating match participation, rating, or rewards. Added a backend regression test for that crash path.
- Backend tests passed 76/76 with `dotnet test Backend/UpdraftBackend.Tests/UpdraftBackend.Tests.csproj --no-restore` (2026-09-28). Unity build/tests were not launched because a Unity Editor was already running. Do not interpret source/config inspection as live server validation.
- `docs/acceptance/STEP_C.md` records the requirement matrix, commands, automated results, failure cases, missing artifact/device evidence, and dependencies. Gate C remains **not accepted** pending six real clients, network shaping, Linux build/run, measured traffic, and failure injection.
