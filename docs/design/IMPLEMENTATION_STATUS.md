# Design Bible implementation tracker

Status recorded 6 October 2026. This is a working checklist, not a completion
claim. The Unity batch editor (6000.3.25f1) now starts, compiles and runs the
suites: EditMode 374/374 and PlayMode 32/34. The two PlayMode failures are
`UiPhysicalSizeTests` (Menus and TutorialAndMatchHud): design CSS-px text and
controls fall below the 12 dp text / 48 dp target floor on the A06 profile. That
is an open conflict between screen parity and the physical-size floor and needs
an owner decision. Device builds have not been run for this pass;
platform-specific Android/iOS haptics and physical-device behavior remain
unverified.
